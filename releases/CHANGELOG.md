# Changelog

## 1.0.0

### Added
- Laptop, portable server, router, flash drive, battery pack, solar panel, floodlight and generator prefabs with Blender-built models.
- armaOS terminal: login, sudo / su, redirection, Tab completion, history, 20 designs, 34 programs, scripts.
- Virtual filesystem with owner / everyone permissions, symlinks, trash, USB mounts, locked and media files.
- Desktop with windows, taskbar, start menu, themes, wallpapers and 21 apps.
- Power grid: generators with fuel, batteries, solar output by sun angle, overload, internal batteries.
- Network: routers with DHCP, static IP, cascading, wireless range and password, SSH policy, ping, messages.
- Mail, chat, in-game web pages and sites, browser history, calendar, CCTV feeds.
- Networked games: chess, checkers, uno, ludo, snakes and ladders, blackjack, rock paper scissors, battleship; Snake.
- Screen content on the laptop model for nearby players.
- Game Master context action "Advanced Equipment..." with an action panel, text form and result notifications.
- World Editor components for users, files, mail, web pages, calendar, power and network links.
- Mission header settings, public script API and events, persistence serializers, named save / restore.
- Per-computer terminal / desktop access lists (player names, faction keys) and per-user transfer speed.
- Positional generator and computer running sounds.
- Olive, Sand and Black device variants; desktop window size setting; model LOD1 meshes.
- Arsenal entries (US, USSR, FIA, CIV) for laptops, routers, battery packs, flash drives and portable servers.
- Inventory sizes: flash drive 1x1, router 2x1, laptop and battery pack 2x2, portable server 3x2 (new slot size).
- Portable server as an inventory item.
- Device textures (plastic, metal, rubber, keys, solar cells) from `tools/gen_textures.py`.
- Inventory and arsenal preview cameras; laptop shown closed.
- Workbench plugin `-ae3Items` inventory inspection.
- Optional `crypto` and `crack` programs (caesar, columnar).
- Terminal `wifi` command; password attempts delayed after failures; per-filesystem storage limit, flash drive capacity enforced.
- Game Master device attributes: power, battery, fuel, root login, interface mode, SSH, router range / accept / external SSH.
- Game Master game settings category "Advanced Equipment" (boot / shutdown time, login, desktop, network, games), sent to all players.
- String table `Language/ROOT_AE3_localization.st` for device names (Game Master browser search).
- Game Master browser preview images for every device and variant; vanilla previews for portable generators and floodlight.
- Workbench plugin `-ae3Dump` writes resources (vanilla configs) to a file.
- Desktop icon set (62 app, file type and glyph icons) from `tools/gen_icons.py`.
- Desktop right-click menus (background, icons, taskbar, Files) and modal dialogs.
- Start menu search box and power menu; taskbar pinned apps (Files, Browser, Mail, Terminal).
- Window snapping (top edge maximizes, side edges fill half), resize grip, fade-in; Ctrl+W closes.
- Files: back / forward, clickable address bar, search box, navigation pane, large icons view, sortable details, properties dialog with owner and permission checkboxes, shortcuts; keys Enter, Backspace, Delete, F2, F5, arrows, Ctrl+C / X / V.
- Desktop Open / Save file dialog; used by Notepad (Open, Save as), Photos (Open) and Remote Access (Download, Upload).
- Calculator keyboard and numpad input; percent, sign change and backspace keys.
- Map zoom (wheel, +/-), pan (drag, arrow keys), Center button and scale bar; device range up to 5 km.
- Games app lobby and table with buttons (new table, join, start, practice seat, leave) and move field.
- Snake plays inside its window (keyboard steering, board size, best score).
- Several mail addresses and chat handles per computer, created and deleted by users; conversations per own handle.
- Calendar event location (World Editor, Game Master, script API, persistence).
- Game bots for all eight games: Add bot / Remove bot, "Play against bot", terminal `bot` / `unbot`, setting `m_bGamesBots`, API `HostGameWithBots`.
- Desktop files and folders from `~/Desktop`; right-click New folder, New text document, Open, Rename, Delete.
- Web and base64 images (PNG, JPEG, GIF) in Photos and as wallpaper, setting `m_bDesktopWebImages`.
- Photos: Web address, Paste base64, Save as, Set as background.
- Personalize: background from an image file or a web address.
- Videos from web addresses in Photos and the Browser (engine VideoWidget; Play, Stop, Restart).
- Browser opens http(s) addresses: page text with links, images and videos in the page area.
- Practice seats: Switch seat (desktop), `seat <number>` (terminal), Game Master setting "Practice seats"; seats named "Practice N".
- Graphical game boards in the desktop Games app for all eight games: drawn boards, cards, dice and tokens; moves by clicking.
- Games app lobby banner with a picture of the game, waiting room with seat cards, table with seat chips and a side panel.
- Rules method `Gui(seat)`: board state for the graphical boards (game_view field 12, seat names after it).

### Changed
- Device variants recolour the body material (router, battery pack, portable server).
- Prefabs list only the material slots their models have.
- Portable server collision uses the vanilla metal game material.
- Solar panel cells sit on top of the frame; back legs end below the panel; LOD1 equals LOD0.
- Desktop, terminal and Game Master panel buttons react to mouse clicks, highlight on hover and press and play the click sound.
- Terminal history on Up / Down only (not W / S); Tab completes in the terminal and moves between login fields. Keys are read directly; no input config override.
- Double click opens desktop icons and list entries and maximizes windows by the title bar.
- Desktop restyled: Windows-like sign-in screen, borderless desktop icons with selection, translucent taskbar with clock and date, flat title bars, shadows, left aligned text; themes use a blue accent (Olive keeps green).
- Text set by script in edit boxes no longer raises change events (fixes the Files app stack overflow and blocked file operations).
- Container frames ignore the cursor; widgets behind them get clicks.
- Editor preview textures built (white Game Master icons).
- Apps renamed: Text Editor to Notepad, Image Viewer to Photos, SSH to Remote Access, Mail to Email.
- Email, Messenger and Calendar laid out as in AE3: Email toolbar with tabs, search and reading pane; Messenger navigation rail, conversation list and bubbles; Calendar month grid with day panel.
- Network app only joins and leaves networks; static IP, SSH toggle and router settings removed from the desktop (Game Master, World Editor, script API).
- Default desktop background plain black (wallpaper 0).
- Boot screen brand FUBAR(TM) Systems (BIOS, copyright 2026, tip, tagline, ASCII art); About and boot art credit Root only.
- Desktop double click works when the first click rebuilds the clicked widget (desktop icons open on double click).
- Game Master "Chat handle" adds a handle to the computer.
- `AddMedia` and Game Master "Add image" accept a texture, a web address (image or video) or base64 text.
- Practice seats allowed by default (`m_bGamesDebugSeats` 1), host only; the computer plays the seat to move, else the chosen one; leaving frees every seat it holds.
- Setting `m_bDesktopWebImages` covers all web access (Game Master "Web access").
- Web and base64 images no longer pass through `string.Trim` / `Substring` (output cut at 8191 characters); images larger than about 6 KB load.
- Binary images cut short by the download (the engine returns web data as text) are reported with the number of bytes received.
- Media files are written with `FileHandle.WriteArray`.
