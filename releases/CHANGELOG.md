# Changelog

## 1.0.0

### Added
- Laptop, portable server, router, flash drive, battery pack, solar panel, floodlight and generator prefabs with Blender-built models.
- armaOS terminal: login, sudo / su, redirection, Tab completion, history, 20 designs, 34 programs, scripts.
- Virtual filesystem with owner / everyone permissions, symlinks, trash, USB mounts, locked and media files.
- Desktop with windows, taskbar, start menu, themes, wallpapers and 21 apps.
- Power grid: generators with fuel, batteries, solar output by sun angle, overload, internal batteries.
- Network: routers with DHCP, static IP, cascading, wireless range and password, SSH policy, ping, messages.
- Mail, chat, in-game web pages and sites, browser history, calendar, CCTV feeds.
- Networked games: chess, checkers, uno, ludo, snakes and ladders, blackjack, rock paper scissors, battleship; Snake.
- Screen content on the laptop model for nearby players.
- Game Master context action "Advanced Equipment..." with an action panel, text form and result notifications.
- World Editor components for users, files, mail, web pages, calendar, power and network links.
- Mission header settings, public script API and events, persistence serializers, named save / restore.
- Per-computer terminal / desktop access lists (player names, faction keys) and per-user transfer speed.
- Positional generator and computer running sounds.
- Olive, Sand and Black device variants; desktop window size setting; model LOD1 meshes.
- Arsenal entries (US, USSR, FIA, CIV) for laptops, routers, battery packs, flash drives and portable servers.
- Inventory sizes: flash drive 1x1, router 2x1, laptop and battery pack 2x2, portable server 3x2 (new slot size).
- Portable server as an inventory item.
- Device textures (plastic, metal, rubber, keys, solar cells) from `tools/gen_textures.py`.
- Inventory and arsenal preview cameras; laptop shown closed.
- Workbench plugin `-ae3Items` inventory inspection.
- Optional `crypto` and `crack` programs (caesar, columnar).
- Terminal `wifi` command; password attempts delayed after failures; per-filesystem storage limit, flash drive capacity enforced.
- Game Master device attributes: power, battery, fuel, root login, interface mode, SSH, router range / accept / external SSH.
- Game Master game settings category "Advanced Equipment" (boot / shutdown time, login, desktop, network, games), sent to all players.
- String table `Language/ROOT_AE3_localization.st` for device names (Game Master browser search).
- Game Master browser preview images for every device and variant; vanilla previews for portable generators and floodlight.
- Workbench plugin `-ae3Dump` writes resources (vanilla configs) to a file.
- Desktop icon set (62 app, file type and glyph icons) from `tools/gen_icons.py`.
- Desktop right-click menus (background, icons, taskbar, Files) and modal dialogs.
- Start menu search box and power menu; taskbar pinned apps (Files, Browser, Mail, Terminal).
- Window snapping (top edge maximizes, side edges fill half), resize grip, fade-in; Ctrl+W closes.
- Files: back / forward, clickable address bar, search box, navigation pane, large icons view, sortable details, properties dialog with owner and permission checkboxes, shortcuts; keys Enter, Backspace, Delete, F2, F5, arrows, Ctrl+C / X / V.
- Desktop Open / Save file dialog; used by Notepad (Open, Save as), Photos (Open) and Remote Access (Download, Upload).
- Calculator keyboard and numpad input; percent, sign change and backspace keys.
- Map zoom (wheel, +/-), pan (drag, arrow keys), Center button and scale bar; device range up to 5 km.
- Games app lobby and table with buttons (new table, join, start, practice seat, leave) and move field.
- Snake plays inside its window (keyboard steering, board size, best score).
- Several mail addresses and chat handles per computer, created and deleted by users; conversations per own handle.
- Calendar event location (World Editor, Game Master, script API, persistence).
- Game bots for all eight games: Add bot / Remove bot, "Play against bot", terminal `bot` / `unbot`, setting `m_bGamesBots`, API `HostGameWithBots`.
- Desktop files and folders from `~/Desktop`; right-click New folder, New text document, Open, Rename, Delete.
- Web and base64 images (PNG, JPEG, GIF) in Photos and as wallpaper, setting `m_bDesktopWebImages`.
- Photos: Web address, Paste base64, Save as, Set as background.
- Personalize: background from an image file or a web address.
- Videos from web addresses in Photos and the Browser (engine VideoWidget; Play, Stop, Restart).
- Browser opens http(s) addresses: page text with links, images and videos in the page area.
- Practice seats: Switch seat (desktop), `seat <number>` (terminal), Game Master setting "Practice seats"; seats named "Practice N".
- Graphical game boards in the desktop Games app for all eight games: drawn boards, cards, dice and tokens; moves by clicking.
- Games app lobby banner with a picture of the game, waiting room with seat cards, table with seat chips and a side panel.
- Rules method `Gui(seat)`: board state for the graphical boards (game_view field 12, seat names after it).
- Inventory "Use" on a carried laptop (uniform, vest, backpack, also in vehicles): wakes or boots it and opens the desktop or terminal.
- Device names: Rename action, Game Master "Rename device", `ROOT_AE3_API.SetDeviceName`; shown in the inventory with hostname, battery, state and flash drives.
- Desktop window size button (taskbar) and F11, stored per player in the profile.
- 77th JSOC EWO mode: AN/PRC-77 (configurable) packs with energy pool, wireless network, laptop charging and power source recharge; EWO panel from inventory "Use".
- AE3 System module (Game Master Systems, World Editor) with all mission settings; device values keep priority.
- Game Master global attributes for EWO; module actions for default root password and EWO pack prefabs.
- `ROOT_AE3_API.SetGlobalNumber` / `SetGlobalText`.
- Accent colour parts (bumpers, stripes, logo plates, caps) and a blue network LED on all device models.
- Flash drives in red, blue and yellow.
- `tools/build_strings.py` builds the runtime string table from the .st file.
- Inventory Use on a carried laptop shows its name field with Open and Rename.
- Inventory Use enabled for gamepad.
- EWO panel for packs carried or placed in the vicinity; it updates every 3 s and closes when the pack is out of reach, the player dies or EWO mode is off.
- Persistence saves the names of all devices and the AE3 System module settings (`ROOT_AE3_SystemModuleSerializer`).
- `ROOT_AE3_DeviceComponent` attribute hidden (set on the EWO router).
- `ROOT_AE3_PowerComponent.SetExternalLoad` / `GetExternalFactor`: loads outside AE3 links served from what consumers leave.
- Game Master action "Connect to network" for single devices: router list with distance, wireless or cable, ignore range.
- Game Master device attribute "Transfer speed".
- Game Master forms show the current values of the device with on / off, choice, multiline, password and permission fields.
- Remote access switch: desktop Network app button, terminal `sshd on|off|status`, `ROOT_AE3_API.SetSshEnabled`.
- `ssh` and Remote Access accept hostnames.
- Setting `m_sDesktopWebImageProxy` (System module action "Web image proxy"): web images load as base64 through `wsrv.nl` by default.
- Editor previews for the airfield and military generators.
- Closed sessions keep the open desktop windows and unsaved text on the client for the same computer and user.
- Network cable items 5 m, 15 m and 30 m (inventory, arsenal, Game Master).
- Plugged network cables and power links are drawn between device ports on every client.
- Desktop styles Windows and Tactical per computer: Game Master attribute "Desktop style", World Editor attribute, setting `m_iDesktopStyle`, `ROOT_AE3_API.SetUiStyle`.
- Two-step cable plugging: network cable from a device to a router (or router to router), power cable from a generator, battery or solar panel to a device; the held end is drawn to the player's hand.
- Power cable length per source (`m_fCableLength`), Game Master actions "Power source" and "Power cable length", `ROOT_AE3_API.SetPowerCableLength`.
- Taskbar search, tray (flash drive, network, power), quick panel, clock opening Calendar and show desktop.
- Floodlight built-in generator (10 L, 0.5 L/h): devices with a fuel tank run without a power source; Game Master attribute "Fuel use" (0 = no fuel used), `ROOT_AE3_API.SetFuelUse`, Refuel and fuel slider on them.
- Desktop style civilian (Windows) / military (Tactical): Game Master panel action "Desktop style" and the Advanced Equipment settings attribute "Desktop style".
- Desktop search finds files as well as apps (start menu and taskbar search).
- Ciphers from Root's Cyber Warfare: Vigenere, ROT, Affine, rail fence, Morse, spelling alphabet, Bacon, substitution, Base32, Base64, Ascii85, Unicode and integer, besides Caesar and Columnar; `crypto` and `crack` take them.
- Sounds: start, shut down, standby, flash drive in / out, error, mail and message chimes (`Sounds/ROOT_AE3`).
- Choice of network cable when several lengths are carried.
- Spare cable length lies in a coil on the floor halfway between the devices.
- Flash drive choice form when several drives are carried; My Computer inserts drives from the inventory; quick panel "Flash drives" button.
- Desktop icons can be dragged freely; other icons keep their place (layout per computer and user); new desktop files go where the menu was opened when free; renamed files keep their place.
- Add file owner "New account": name and password, creates the account when missing.
- Desktop right-click "Sort by" (name, type, size), "Group by" (none, type) and "Align icons to grid".
- Inventory "Use" on a flash drive, router or battery pack opens the name form; a flash drive name is its label.

### Changed
- Device variants recolour the body material (router, battery pack, portable server).
- Prefabs list only the material slots their models have.
- Portable server collision uses the vanilla metal game material.
- Solar panel cells sit on top of the frame; back legs end below the panel; LOD1 equals LOD0.
- Desktop, terminal and Game Master panel buttons react to mouse clicks, highlight on hover and press and play the click sound.
- Terminal history on Up / Down only (not W / S); Tab completes in the terminal and moves between login fields. Keys are read directly; no input config override.
- Double click opens desktop icons and list entries and maximizes windows by the title bar.
- Desktop restyled: Windows-like sign-in screen, borderless desktop icons with selection, translucent taskbar with clock and date, flat title bars, shadows, left aligned text; themes use a blue accent (Olive keeps green).
- Text set by script in edit boxes no longer raises change events (fixes the Files app stack overflow and blocked file operations).
- Container frames ignore the cursor; widgets behind them get clicks.
- Editor preview textures built (white Game Master icons).
- Apps renamed: Text Editor to Notepad, Image Viewer to Photos, SSH to Remote Access, Mail to Email.
- Email, Messenger and Calendar laid out as in AE3: Email toolbar with tabs, search and reading pane; Messenger navigation rail, conversation list and bubbles; Calendar month grid with day panel.
- Network app only joins and leaves networks; static IP, SSH toggle and router settings removed from the desktop (Game Master, World Editor, script API).
- Default desktop background plain black (wallpaper 0).
- Boot screen brand FUBAR(TM) Systems (BIOS, copyright 2026, tip, tagline, ASCII art); About and boot art credit Root only.
- Desktop double click works when the first click rebuilds the clicked widget (desktop icons open on double click).
- Game Master "Chat handle" adds a handle to the computer.
- `AddMedia` and Game Master "Add image" accept a texture, a web address (image or video) or base64 text.
- Practice seats allowed by default (`m_bGamesDebugSeats` 1), host only; the computer plays the seat to move, else the chosen one; leaving frees every seat it holds.
- Setting `m_bDesktopWebImages` covers all web access (Game Master "Web access").
- Web and base64 images no longer pass through `string.Trim` / `Substring` (output cut at 8191 characters); images larger than about 6 KB load.
- Binary images cut short by the download (the engine returns web data as text) are reported with the number of bytes received.
- Media files are written with `FileHandle.WriteArray`.
- Picking up a laptop keeps its flash drives plugged in; port props are hidden while carried and return when placed.
- Picking up a laptop ends only other players' sessions; the carrier's session continues.
- Carried laptops stay on wireless networks within range of the carrier.
- Variants recoloured: Black with orange, Olive with coyote, Sand with ranger green accents; brighter plastics.
- Game Master previews re-rendered in the variant colours.
- Inventory Use closes the inventory through `Action_CloseInventory`.
- Carried computers do not mirror their screen and go to standby when their session ends.
- Restoring a save into a carried laptop does not spawn flash drive props; the pick-up listener is set at init.
- Sessions on a placed laptop end when its lid is closed.
- EWO networks get a random 8 character password and the lowest free gateway number 1-254; the router exists only while broadcasting, is hidden from the Map app and is configured only when name or password change.
- EWO recharge loads the power source; pack state stays while EWO mode is off.
- Rename and EWO requests are rate limited per player.
- AE3 System module applies its settings at init; only the active module can be edited; deleting it activates the next module or the mission defaults.
- Power update interval follows setting changes at runtime.
- Numeric settings are clamped to their attribute ranges; Game Master EWO energy slider up to 5000, range up to 1000.
- Desktop window size default Large; changing it keeps open windows and their content; taskbar button labelled "Size".
- Inventory tooltip labels in the string table; the Use hint only on computers.
- Larger variant accents (laptop side bands and lid plate, router and battery bands, server top plate); solar panel frame and legs take the variant colour, accent rim on the panel; previews re-rendered.
- Game Master "Router settings" is "Router name and password" (SSID, password, SSH allow list); range, accept connections and external SSH are device attributes.
- Game Master "Add file": content field multiline, owner from the computer users, permission buttons, encryption choice with its key field, optional shown size; failures name the reason.
- Game Master "Connect network (selection)" is "Connect selection to router".
- Laptops accept SSH logins by default.
- SSH to a computer in standby or with remote access off names the cause.
- Plugging a flash drive mounts it at `/mnt/usbN`; empty `/mnt/usbN` folders take no files and list "No drive in usbN".
- Floodlight lights only on machines with a display and unsubscribes from the power state on delete.
- Floodlight and solar panel prefabs have no parent prefab (duplicate mesh and physics components blocked placing).
- Flash drive props sit in the USB port, plug into the case, on both sides of the laptop.
- Remote Access: connect card with recent hosts, then a file browser with back, forward, up, refresh, address bar, icons, preview and context menu.
- Ping, System Info, About, Settings and My Computer apps rebuilt (result log, cards, meters, navigation pane).
- Game boards and Snake draw in the same units as their click areas: boards fill the window and clicks hit the right square at any resolution.
- The Terminal desktop icon switches to the terminal without opening a window; the next session opens on the desktop.
- Inventory "Use" on a carried laptop opens it directly; waking from standby shows no "Starting..." note.
- Map app (setting on by default): only the computer, its router, routers linked to it and devices connected to it.
- Game Master slider attributes no longer log "Incompatible parameter" (vanilla slider change handler).
- Flash drive props attach in the port (child transform was taken as a world transform) and stay attached while the laptop is carried.
- Network cable weights: 5 m 0.05 kg, 15 m 0.1 kg, 30 m 0.2 kg.
- Network cable collider uses the gadget plastic surface (wrong game material reference).
- Generators, solar panel and battery take power cables; generators and the floodlight have power port positions.
- Taskbar no longer stops with "Wrong parameter value" before the first tray update.
- Cable lines are built from segment entities (`ROOT_AE3_CableSegment.xob`) instead of a procedural mesh, which crashed Workbench when drawn.
- Game Master "Add file" form: where (desktop or home of a user, top folder, other folder), file name, who can open it, protection (password, cipher or both) with one key field per cipher.
- Network cables 7 mm and power cables 11 mm thick; cable lines stay above the floor under them.
- Terminal: the prompt and typed text follow the last line with a cursor; no blank line after each command and no empty line sent when the input is refocused.
- Military style: no grid lines on the desktop; the sign-in panel and outlined borders keep their edges at UI scales below 1.
- Desktop keeps an opaque base layer under the background.
- Picking up a device with a network cable puts the cable item into the carrier's inventory or at the carrier's feet.
- README and wiki rewritten by audience (players, Game Master, World Editor, server admins, systems, reference, developers).
- Game Master forms: choice buttons wrap into a grid that fits the labels; shorter Add file and cipher labels.
- UI sounds 20 dB quieter; the switch sound plays only for players out of chime range.
- Terminal input keeps focus after Enter.
- Cable ports on the laptop, router, portable server, solar panel and battery pack moved to the back of the models (were mirrored to the front); port directions default to +Z; ports use the world transform.
- Cable lines use up to 320 segments so long cables keep their thickness.
- Laptop, router, battery pack and portable server actions moved to the "Pick up" action point.
- Device actions that cannot run are hidden (insert flash drive, power, wake, refuel, use, power and network cable).

### Removed
- Power plug into the nearest source within 6 m (replaced by the power cable taken from the source).
- Plain base laptop, router, battery pack, solar panel and portable server from Game Master and arsenals (3 variants each remain).
