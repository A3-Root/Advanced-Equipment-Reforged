# Changelog

## 1.0.0

### Added
- Laptops, portable servers, routers, flash drives, batteries, solar panels, floodlights and generators.
- Terminal and desktop interfaces with files, folders, permissions, accounts, applications, themes and wallpapers.
- Virtual filesystem with symlinks, trash, USB storage and media files.
- Power system with generators, batteries, solar output, fuel, cables and overload protection.
- Network system with wired and wireless links, DHCP, static IPs, SSH, passwords, ping, mail, chat, web pages and CCTV.
- Networked games: chess, checkers, Uno, Ludo, Snakes and Ladders, blackjack, rock paper scissors and Battleship.
- Game bots for all networked games.
- Game Master controls for devices, power, networks, files, users, media, access, fuel and desktop settings.
- World Editor components for users, files, mail, web pages, calendars, power links and network links.
- Mission settings, script API, events and persistence for devices, names and system settings.
- Practice seats for testing computer users and games.
- Remote Access file browser and SSH access.
- Computer, router, battery, flash drive, portable server and cable inventory items.
- Olive, Sand, Black, Windows and Tactical device variants.
- 77th JSOC EWO packs with wireless networks, laptop charging and power recharge.
- Device sounds, screen displays, inventory previews and Game Master previews.
