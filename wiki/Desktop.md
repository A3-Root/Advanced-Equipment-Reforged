# Desktop

Opened with "Use desktop" or the `desktop` command. Login screen, wallpapers 1-5, themes Dark / Light / Olive,
draggable windows, taskbar, start menu, notifications. Window size: setting `m_iDesktopSize`.

| App | Use |
| --- | --- |
| My Computer | Volumes, flash drive mount and eject |
| Files | Browse, copy, move, link, delete to Recycle Bin, permissions, owner, search, unlock |
| Text Editor | Edit text files |
| Image Viewer | Image files (`AE3_MEDIA|image|...`) |
| Terminal | Switches to the terminal view |
| Browser | Registered web pages, history |
| Mail | Inbox, sent, compose between registered addresses |
| Messenger | Chat by handle |
| Calendar | Events |
| Network | Scan, connect, static IP, SSH toggle, router settings |
| SSH | Remote file list, read, pull, push |
| Ping | Reachability |
| Map | Devices nearby (same network only with `m_bDesktopMapSameNetworkOnly`) |
| CCTV | Every registered camera (renders through world camera index 3) |
| Games | Network games as text |
| Snake | Snake |
| Calculator, Recycle Bin, Settings, System Info, About | |
